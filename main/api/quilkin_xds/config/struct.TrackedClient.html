Struct TrackedClient 

Source 
pub struct TrackedClient(/* private fields */);
Expand description

A ClientTracker that releases its client’s series when it goes.

The series are keyed by a name the client chooses for itself, so a server that never releases them keeps a set for every client that has ever connected. Dropping is the only point every path shares: a stream ends by being dropped as often as it ends by returning.
